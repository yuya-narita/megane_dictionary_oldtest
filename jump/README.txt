JUMP BEFORE PLAYER v0.1

作品:
跳ねる前のこの感じ

コンセプト:
「立ち止まるように、読む。」

内容:
- 専用の朝焼け・生成りテーマ
- タップで一文ずつ進行
- 穏やかなフェードと広い余白
- 作品本文をScene化した第1話サンプル
- 読了後「今日も、まだ。」
- 続きから再開
- AUTO対応
- BGM ON/OFF対応

使い方:
1. index.htmlをブラウザで開く
2. GitHub Pagesへ置く場合はフォルダ一式をそのままアップロード
3. BGMを使う場合は audio/jump_before_theme.mp3 を配置

Scene Studioで作った話を追加する場合:
- ep/ep002.js などを配置
- series.js の episodes に追記
